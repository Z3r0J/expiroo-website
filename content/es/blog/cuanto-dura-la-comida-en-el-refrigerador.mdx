La carne picada aguanta un día o dos; un queso curado, semanas. Cuánto dura la comida en el refrigerador (o nevera, en España) no tiene una única respuesta: depende del alimento y, sobre todo, de la temperatura real que mantiene el aparato. Abajo tienes una tabla de conservación práctica, con la fuente citada, para ver cuántos días aguanta cada cosa.

## La regla: el refrigerador a 4 °C o menos

Todos los tiempos de esta guía asumen un refrigerador a **4 °C (40 °F) o menos**. Si el tuyo está más caliente, todos los plazos se acortan. Si solo cambias una cosa, revisa el termostato.

## Tabla de conservación (fuente: USDA, EE.UU.)

La **AESAN no publica una tabla numérica por alimento**, de modo que esta se apoya en la referencia del **USDA / FoodSafety.gov de EE.UU.**, adaptada a un refrigerador a 4 °C ([FoodSafety.gov](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts)):

| Alimento | Refrigerador (4 °C) |
| --- | --- |
| Carne picada | 1–2 días |
| Pollo o pavo fresco | 1–2 días |
| Filetes, chuletas, asados | 3–5 días |
| Bacon | 7 días |
| Salchicha cruda | 1–2 días |
| Fiambre / embutido loncheado | abierto 3–5 días / cerrado 2 semanas |
| Salchichas tipo Frankfurt | abiertas 1 semana |
| Huevos con cáscara | 3–5 semanas |
| Huevo duro | 1 semana |
| Leche | 7 días |
| Yogur | 7–14 días |
| Queso crema | 2 semanas |
| Queso curado (abierto) | 3–4 semanas |
| Sobras cocinadas | 3–4 días |
| Sopas y guisos | 3–4 días |
| Pizza | 3–4 días |
| Pescado fresco | 1–2 días |
| Pescado cocinado | 3–4 días |
| Marisco fresco | 1–2 días |

## El consejo de la AESAN

Por encima de cualquier tabla general, la AESAN recomienda **seguir siempre las instrucciones de conservación del envase**, que son específicas de cada producto ([AESAN](https://www.aesan.gob.es/AECOSAN/web/para_el_consumidor/ampliacion/fechas_caducidad.htm)). Y no olvides la diferencia entre **fecha de vencimiento** (o caducidad) y consumo preferente: la primera marca el límite de seguridad; la segunda, solo de calidad.
